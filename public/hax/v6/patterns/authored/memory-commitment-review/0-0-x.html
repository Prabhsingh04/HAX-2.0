Platform runbook

Last updated · 2h ago

Default deploy target

Platform engineering is standardizing all new service deploys on the us-east-1 EKS cluster. Existing services may remain on legacy clusters until migrated during their next major release.

Change requests should reference the cluster name in the deployment manifest. The deploy review checklist now includes a cluster validation step before merge.

Network firmware cadence

The Q3 router firmware target is IOS-XE 17.9.2 for edge routers in production. Staging environments may lag by one minor version during validation windows.

Maintenance windows for core routing changes remain after 10pm ET to minimize customer impact. Coordinate with the network operations channel before scheduling.
